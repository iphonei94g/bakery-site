# Тёплая крошка

Статический сайт-визитка для пекарни. Не требует сборки и готов к публикации на GitHub Pages.

## Перед публикацией

1. В `index.html` замените название бренда, город, номер телефона и ссылку Telegram (`your_username`).
2. При желании замените иллюстрации в карточках товаров на фотографии ваших изделий.
3. Загрузите файлы в репозиторий GitHub и включите Pages в настройках репозитория: **Settings → Pages → Deploy from a branch → main / root**.

Сайт использует Google Fonts, поэтому при открытии с подключённым интернетом загружаются шрифты Playfair Display и DM Sans. Без них сайт всё равно отображается с системными запасными шрифтами.
